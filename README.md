# CodeAlpha Python Internship — Task 2: Stock Portfolio Tracker

## Project overview
This beginner-friendly console program calculates the total investment value of stocks using manually defined sample prices and quantities entered by the user.

## Features
- Displays a list of available sample stocks and their prices.
- Accepts a stock name and quantity from the user.
- Calculates each stock investment: quantity × price.
- Calculates the total investment.
- Handles unknown stock names, invalid quantities, and non-positive quantities.

## Python concepts used
- Dictionaries
- `while` loops
- `if-else` conditions
- Lists and tuples
- `input()` and type conversion
- `try-except` error handling
- Arithmetic and formatted output

## Requirements
Python 3.8 or newer. No external libraries are needed.

## How to run
Open a terminal in this folder and run:

```bash
python main.py
```

On Windows, you can also try:

```bash
py main.py
```

## How to use
1. Choose a stock from the displayed list: TCS, INFOSYS, WIPRO, RELIANCE, or HCL.
2. Enter the quantity you want to track.
3. Add more stocks if you wish.
4. Type `done` when you have finished.
5. The program displays each investment and the total.

## Important note
Prices are sample values defined in the code for learning purposes. They are not live market prices or investment advice.
